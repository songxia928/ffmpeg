# 04.ffprobe、ffplay命令


## 1 ffprobe

### a. 显示文件信息
```shell
ffprobe  xxx.mp4    # 不会显示视频帧数，只有时长
```


### b. 显示视频帧数
```shell
ffprobe -v error -select_streams v:0 -count_packets -show_entries stream=nb_read_packets -of csv=p=0     xxx.mp4


    -v error 这隐藏了“信息”输出（版本信息等），使解析更容易（但如果您在隐藏重要信息时要求帮助，则更加困难）。

    -count_frames 计算每条流的数据包数，并在相应的流部分中报告。

    -select_streams v:0 仅选择第一个视频流。

    -show_entries stream=nb_read_packets 只显示条目 nb_read_frames.

    -of csv=p=0 设置输出格式。在这种情况下，它隐藏了描述，只显示值。看 FFProbe作家 有关其他格式的信息，包括JSON。

```
